## El sitio

Un solo `index.html`, sin build ni dependencias. El contenido, la tipografía y el color
viven todos en ese archivo, y los logos van incrustados —nada depende de rutas externas,
así que nada se rompe—. El detalle que más me gusta es la espina vertical que se llena
con el scroll.
